# Code of Conduct

Be respectful, assume good faith, critique the content not the person. No harassment, discrimination, or personal attacks. Maintainers may edit, reject, or remove contributions and block repeat offenders. Report concerns to the maintainer via a private security advisory at https://github.com/AbhinavTrips/ramesh/security/advisories/new.

This project gives engineering guidance, not legal advice. Do not post confidential or client-privileged information, or anyone's personal data, in issues or PRs.
