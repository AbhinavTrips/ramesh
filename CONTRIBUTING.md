# Contributing

Ramesh is only useful if it is **correct**. Wrong legal claims hurt people more than missing ones.

- Every legal claim (section, deadline, penalty, threshold) must link to an official source (gazette, meity.gov.in, cert-in.org.in, rbi.org.in, sebi.gov.in, irdai.gov.in) in the PR description.
- If you are unsure, write "verify" instead of guessing.
- Keep each SKILL.md short and actionable: what a developer must do, not legal essays.
- Prefer a checklist item or code pattern over a paragraph.
- Update `Last reviewed` in the README when you re-verify a skill.
- Lawyers, DPOs, and security folks: reviews are the most valuable contribution. Open an issue tagged `legal-review`.
- Regional language versions of the user-facing parts (notice, consent copy) are welcome.

Ideas wanted: sector skills (health/ABDM, fintech/RBI, edtech, gaming), consent-UI code patterns per framework, a CI linter for PII in logs, a DPDP data-inventory template.
